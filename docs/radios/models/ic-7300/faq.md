# IC-7300 FAQ

## Basic connection

Start with the IC-7300 USB CI-V device and Auto baud. Auto is the normal recommendation for CAT.

## Waterfall

The IC-7300 scope has additional radio-side requirements and USB may deliver only a few fresh sweeps per second. If the scope is blank, display it on the radio, close setup menus, verify USB routing, and reconnect. If CAT works but scope data does not, test fixed 115200 at both ends.
