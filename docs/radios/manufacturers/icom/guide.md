# Icom CI-V manufacturer guide

1. Connect the radio directly by USB and identify its serial device.
2. Select the exact model, or CI-V (generic) when no profile applies.
3. Start with Auto baud and confirm ordinary CAT control.
4. Enable CI-V Transceive for unsolicited frequency and mode updates.
5. For scope use, follow the model guide for USB routing, baud, scope visibility, and menu state.
