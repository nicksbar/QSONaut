# Icom CI-V manufacturer FAQ

## Common questions

- Auto baud is the recommended starting point for ordinary CI-V control.
- A working CAT link does not guarantee a native scope stream; scope support and prerequisites vary by model and transport.
- For a blank scope, confirm the radio scope is visible, setup menus are closed, the selected model supports scope data, and reconnect after changing CI-V settings.
- USB scope rates can be much slower than the radio's local display because the radio sends scope data over its control transport.
